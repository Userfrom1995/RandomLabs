FAQ

Is there a single winner?

No. Every headline is a paired comparison on one workload with a 95% bootstrap CI plus Holm correction. The same pooler can win one claim and lose another; read the dossier tables, not a score.

Why do some cells read timeout/inconclusive?

Per-cell caps (8 min standard, 12 flagship) stop a stalled arm instead of letting CI burn. Timeouts are published findings with nulls, never zeros, never retried into a pass.

What does N/A (unsupported) mean?

The pooler has no such mode (for example Supavisor statement mode). N/A rows carry nulls and are never interpolated or gap-filled on charts.

Can I reproduce a cell?

Yes: reproducibility runbook gives the one-command repro plus the per-cell recipe any maintainer could re-run.

Do the numbers apply to my hardware?

No. Numbers are valid for the stated iron and PG 17 build only (see spec-v1.md hardware envelope). Compare deltas inside the stated envelope, never absolute capacity.

Why is Claim 4 inconclusive?

Its paired CI did not exclude zero (or it depended on quarantined evidence), so the kill rule fired: it ships as inconclusive, never as a win.

Glossary

Transaction pooling
Backend assigned per transaction, returned at COMMIT/ROLLBACK. Highest sharing; breaks session state and server prepares unless virtualized.
Session pooling
Backend held for the whole client session. Safest semantics; lowest sharing under churn.
Statement pooling
Backend assigned per statement (PgBouncer-class). Only some poolers implement it; elsewhere N/A.
Churn (-C)
pgbench reconnects per transaction, pricing connect/fork cost. The equalized M9-E1 control runs SCRAM everywhere.
Powered repeats
Flagship n>=10, standard n>=7, paired seeds across arms; headlines need CI-excludes-zero plus Holm.
Kill rule
A claim whose CI includes zero (or leans on quarantined p-latency) ships inconclusive, never a win.
Quarantine
p-latency flagged untrustworthy by the parser forensics stays published but cannot carry a headline.
Flatness
Whether a pooler is fast everywhere or at one magic setting; peaks always ship with exact configs.
Iso-region
Comparison restricted to cells sharing identical geometry (clients, backends, duration).
Reproducibility-by-adversary
Disclosure complete enough that a pooler maintainer could re-run a cell or file a founded objection.
