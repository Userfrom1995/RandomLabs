Statistics (M10 rebuild; old gate retired)

Headlines use paired-difference bootstrap 95% CIs (B=5000, seed 20260914, deterministic) with Holm step-down at alpha 0.05. A headline needs CI-excludes-zero plus Holm-adjusted p below alpha plus no quarantine label. Outliers follow Tukey IQR fences (1.5 flag / 3.0 extreme) with a trimmed-mean sensitivity check; a flip demotes to inconclusive with forensics retained. Per-repeat p99/p999 feed the machinery at repeat level, never pooled; quarantined p-latency forces tps-only verdicts labeled on-figure. The old min-max-band plus tps/p99-agreement gate stays in harness/stats.py for backward comparison only.

Disclosure minimums

Every measured cell publishes throughput plus p99/p999 plus errors with medians over repeats; peaks carry exact configs verbatim in docs/configs/; N/A rows carry nulls; timeouts stay timeout/inconclusive with nulls. Raw JSON plus medians are committed; any version upgrade means a re-run, never carried-forward numbers.

Threats to validity (mandatory)

  • Shared-runner variance: medians plus paired seeds damp it but never remove it; cross-machine comparison is forbidden.
  • Single PG build and dataset scale per leg: scale-100 C block exists to test the scale threat, not to erase it.
  • Churn auth asymmetry in early legs (SCRAM everywhere only from M9-E1); read the auth posture per row.
  • Short-query bias: pgbench TPC-B-like plus SELECT-only plus churn plus prepared twins; Zipf/think-time/multi-statement breadth lands with calibration.
  • Timeout caps censor the left tail: a timeout is a finding about the cap, not a ranking proof.
  • Supavisor is a new contender: M9 twins are its first measured evidence; statement N/A is by design.
