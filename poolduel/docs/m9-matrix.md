## Scope decisions (logged per section-0 mandate)

1. **M1 IDs reused, C IDs new.** R-block rows keep M1-1..M1-7 IDs
   (raw lands in `poolduel/results/m9/`, never beside M1/M2 medians;
   every record carries seed + repeat). C-block rows need new IDs
   (M9-C1..C7) because medians key on `(cell_id, pooler)` and the same
   ID at two scales would collide in one `medians.json`.
2. **M8-P1..P3 subsumed by M9-C1..C3.** Same geometries, powered
   repeats: the pilot evidence and the scale-100 matrix are one block,
   not two runs of the same cells. The M8 pilot spec stays as the
   calibration definition; M9-C1..C3 are its measurement.
3. **M2 at scale 100 deferred to M9b.** Full M2 x scale-100 doubles
   the sweep (~24 more measured hours plus 1.5 GB inits) before the
   iron has proven it holds `-s 100`. The C block is the gate: if its
   medians are healthy, M9b extends the W/U pattern to scale 100;
   if not, the scale finding is published from C alone. No silent
   carry-forward either way.
4. **Native absent, not N/A.** No matrix row probes passthrough, so
   there is nothing to twin; the U block maps transaction/session
   only. Statement twins (T1-T4, P3-P4) are N/A with reason.
5. **pgagroal `performance` twins map to session.** Dedicated-backend
   class; closest Supavisor analogue is session. The comparison is
   geometric (same clients/pool/workload), never mode-identical;
   best-vs-best plus iso slices carry the verdict in M10.
6. **Odyssey E1 password form.** `scram-sha-256` with a plaintext
   `password` per the rules.html password reference; CI startup
   proves it. A rejection fails loudly at healthcheck and quarantines
   the E1 odyssey arm with artifact evidence (no substitution).

## Repeats and seeds (plan section 5)

Flagship cells n=10, standard cells n=7, curve points n=3. Seeds come
from `m9_seed_for(repeat, base_seed)`: three bases cycling with a
7919 stride (offsets 0/1295/8959, none a multiple of the stride, so
seeds stay distinct for every repeat at any base). The schedule is a
function of the repeat only, never the arm: repeat r runs on the
identical seed on all 8 arms (pairing for the M10 CIs). `--seed`
overrides the base; the default base is 42.

## Pricing

78.1 measured hours across 103 parallel chunks (worst chunk 56 min
measured, cap 60). Per-chunk fixed wall clock adds pooler builds
(~15 min one-time per job) plus dataset init (`-s 10` ~1 min,
`-s 100` ~2-5 min): budget ~85 min wall per chunk, ~90 min
dispatch-to-commit with the aggregate job. Sequential local repro
(`repro.sh --m9-full`) is ~120 h; CI parallelizes it to one wave.

## Provenance

Every M9 record carries `seed`, `repeat`, `pg_show`, `pg_config_status`,
`isolation`, `auth_posture` (E1 rows label the equalized control),
`resources`, and `dataset` (scale-aware init policy). Rerun rule:
any version/SHA bump re-runs the affected block, never carried-forward
numbers.
