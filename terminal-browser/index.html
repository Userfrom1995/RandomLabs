Terminal Browser

An agent-first browser that runs completely in the terminal: real pages, real sessions, real graphics in the grid. Humans and AI agents hold identical capabilities through a shared control plane.

Go single binaryChromium CDP sidecarKitty / Sixel / iTerm2 / blockMCP + CLI parity

Quickstart

cd terminal-browser
go build ./...
./tb --fixture home --tier block --dump-stats
TB_TIER=sixel ./tb-agent render --fixture article
go test ./...

Run the interactive shell with go run ./cmd/tb in a real terminal. q quits, / edits the address, ? shows all keys.

Command reference

CommandWhat it does
tbInteractive terminal browser shell (tabs, address bar, status line).
tb --fixture NAME --tier TRenders one fixture page offscreen through the full paint pipeline.
tb-agent probeReports terminal capabilities as a JSON envelope.
tb-agent render --fixture NAME --graphics-tier TRenders a fixture page and reports bytes, cells, painter, tier.

Agent protocol

Every agent command returns the shared envelope {success, data, warning?, code?}. Snapshot-first discipline: observe with refs, act by ref, re-snapshot on ref_stale. Full tool matrix and conformance rules live in docs/architecture.
