Terminal Browser

An agent-first browser that runs completely in the terminal: real pages, real sessions, real graphics in the grid. Humans and AI agents hold identical capabilities through a shared control plane.

Go single binaryChromium CDP sidecarKitty / Sixel / iTerm2 / blockMCP + CLI parity

Quickstart

cd terminal-browser
go build ./...
./tb --fixture home --tier block --dump-stats
./tb --url https://news.ycombinator.com/ --tier block --dump-stats
./tb-agent fetch --url https://news.ycombinator.com/ --lite
go test ./...

Run the interactive shell with go run ./cmd/tb in a real terminal. q quits, / edits the address (http(s) URLs fetch live, fixture:// stays local), H/L step back/forward, r reloads, p switches profile, ? shows all keys.

Command reference

CommandWhat it does
tbInteractive terminal browser shell (tabs, address bar, status line).
tb --fixture NAME --tier TRenders one fixture page offscreen through the full paint pipeline.
tb --url URL [--profile P] [--lite]Fetches one live page through the engine and paints it through the full pipeline.
tb-agent probeReports terminal capabilities as a JSON envelope.
tb-agent render --fixture NAME --graphics-tier TRenders a fixture page and reports bytes, cells, painter, tier.
tb-agent fetch --url URL [--lite] [--width W]Fetches a live page and reports rows, cold timing, jar sync counts, JS probe, Chrome version.
tb-agent cookies [--profile P]Lists the persisted cookie jar for a profile.
tb-agent cookies-set --name N --value V --domain D [--profile P]Inserts a jar row; installs into the next live navigation.
tb-agent history [--query Q] [--limit N] [--profile P]Queries visits newest-first with substring filter.
tb-agent bookmark-add --url U [--title T] [--profile P]Saves a bookmark; bookmarks lists, bookmark-remove deletes.
tb-agent session [--profile P]Reports the back/forward stack; session-back, session-forward, session-reload step it.
tb-agent state-save --file F [--profile P]Exports cookies, bookmarks, and stack; state-load imports them back.

Agent protocol

Every agent command returns the shared envelope {success, data, warning?, code?}. Snapshot-first discipline: observe with refs, act by ref, re-snapshot on ref_stale. Full tool matrix and conformance rules live in docs/architecture.
