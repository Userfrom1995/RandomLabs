# Designs: original fighter sheets (Phase 1)

All sheets are hand-authored SVG sources in this folder. No binary without a
generator; no third-party likeness (see `../story/IP-DECLARATION.md`).

- `thor-model.svg`: Thor model sheet. Broad low brawler, 7.0 heads, shoulders
  2.1 heads, braid 2.4 heads with iron ring, beard 1.2 heads. Front plus side
  plus effort faces plus palette notes.
- `zeus-model.svg`: Zeus model sheet. Tall upright striker, 7.4 heads,
  shoulders 1.8 heads, himation drape 2.0 heads, narrow high stance. Front plus
  side plus effort faces plus palette notes.
- `weapons.svg`: original weapon sheets. The northern haft-hammer `hafra`
  (long ash haft, compact wedge head, lanyard) and the Olympian shaft-bolt
  `keraunos-rod` (tapered shaft, faceted glass-bronze head), plus 390 px
  silhouette reads.
- `palettes.svg`: palette plate shared with the arena paint pass (Phase 2).

Turnaround note: front/side pairs on each sheet are drawn to the same
head-unit grid; mirror symmetry is verified by the craft tests from Phase 3.
