Kestrel

A neural-network library built from scratch in Julia. Zero dependencies, standard library only.

Playground · README

Why from scratch

ML is usually a black box imported from a framework. Kestrel is backprop you can read line by line: a reverse-mode autodiff tape, dense layers, softmax and cross-entropy, and a mini-batch SGD training loop, all written by hand on top of plain Julia arrays.

The autodiff tape

A Var wraps an array value and an optional gradient, and remembers the operation that produced it. Each operation stores a backward closure: given the gradient of the output, it computes the gradient of its inputs. After a forward pass, backward! walks the tape in reverse, applying the chain rule, and each Var ends up holding dL/dx.

Implemented ops: matmul, add, subtract, negate, broadcast multiply, broadcast unary (relu, sigmoid, tanh, exp, log), sum, mean, transpose, permutedims, reshape, and fused stable softmax and cross_entropy (max-shifted so the exponentials never overflow). The test suite checks every gradient against a central finite-difference estimate.

Data

Kestrel.synthetic_digits(n) renders a built-in 5x7 bitmap font into 28x28 images with random shifts, scaling, rotation, blur, and noise, so the whole pipeline runs offline and deterministically. Kestrel.load_mnist() reads the real MNIST IDX files from data/; scripts/download_mnist.jl fetches them. Both return (images, labels) with 784-vectors normalized to [0, 1].

CLI

julia --project=. bin/kestrel.jl train  --epochs 3 --out model.json
julia --project=. bin/kestrel.jl eval   --model model.json
julia --project=. bin/kestrel.jl export --model model.json --out weights/mnist.json
julia --project=. bin/kestrel.jl autograd-check
julia --project=. bin/kestrel.jl selftest

Playground

index.html loads the exported weights and runs a dependency-free JS mirror of the network. Draw a digit; the probability bars update live.

Verification

  • Autodiff gradients vs finite differences (all ops, random shapes).
  • XOR convergence: a 2-4-1 net learns XOR under 2k SGD steps.
  • Synthetic-digit training reaches high accuracy headlessly.
  • Model save/load round-trips weights exactly; export matches load.
