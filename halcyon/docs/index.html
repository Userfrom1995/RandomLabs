Halcyon

A small functional language with Hindley-Milner type inference and a bytecode VM. Written in Haskell as a zero-dependency CLI, and mirrored one-to-one in plain JavaScript so the whole language runs in the browser, VM debugger included.

Try the playground

What it is

Halcyon is a from-scratch functional programming language: a lexer, recursive-descent parser, Algorithm W type inference (with let-polymorphism), a tree-walking interpreter, a bytecode compiler, and a stack VM with frames, upvalue cells, closures, tail-call optimization, an instruction profiler, and a deterministic optimizer. Algebraic data types, nominal records, and type classes let programs define their own types. Two evaluators (interpreter and VM) plus a JavaScript mirror all agree byte-for-byte, proven by a differential corpus.

Types

Full Hindley-Milner inference: Int, Float, Bool, String, Char, lists, functions, user-defined algebraic data types, nominal records, and real polymorphism through let.

Classes

Type classes with dictionaries: class/instance declarations, runtime method dispatch, and contextual instances like instance Show a => Show (Maybe a).

VM

A single-steppable stack machine with tail-call optimization and profiling. halcyon run-vm --trace, run-vm --profile, and the web debugger drive the exact same instruction set.

Playground

A dependency-free index.html that runs the whole language client-side: edit, typecheck, run, disassemble, profile, step, and toggle the optimizer with --opt.

Verified

596 Haskell self-tests, a differential corpus, and a cross-language check (JS interpreter == JS VM == Haskell expected, including the profiler and disassembly).

Quick start

let rec fib = fn n => if n < 2 then n
               else fib (n - 1) + fib (n - 2)
in fib 25

The pipeline is lex -> parse -> infer (optional) -> eval, or -> compile -> vm. The CLI dispatches both paths; the playground offers the buttons for each stage.

Example

data Tree = Leaf Int | Node Tree Tree
let rec height = fn t => match t with
  | Leaf n => 1
  | Node l r =>
      let hl = height l in
      let hr = height r in
      if hl > hr then hl + 1 else hr + 1
in height (Node (Node (Leaf 1) (Leaf 2)) (Leaf 3))

prints 3 on every backend: interpreter, VM, and playground. Data types, records, classes, pattern matching, and recursion work identically across the Haskell core and the JS mirror.
