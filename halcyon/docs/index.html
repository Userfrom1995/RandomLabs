Halcyon

A small functional language with Hindley-Milner type inference and a bytecode VM. Written in Haskell as a zero-dependency CLI, and mirrored one-to-one in plain JavaScript so the whole language runs in the browser, VM debugger included.

Try the playground

What it is

Halcyon is a from-scratch functional programming language: a lexer, recursive-descent parser, Algorithm W type inference (with let-polymorphism), a tree-walking interpreter, a bytecode compiler, and a stack VM with frames, upvalue cells, and closures. Two evaluators (interpreter and VM) plus a JavaScript mirror all agree byte-for-byte, proven by an 18-program differential corpus.

Types

Full Hindley-Milner inference: Int, Float, Bool, String, lists, functions, and real polymorphism through let.

VM

A single-steppable stack machine. halcyon run-vm --trace and the web debugger drive the exact same instruction set.

Playground

A dependency-free index.html that runs the whole language client-side: edit, typecheck, run, disassemble, and step.

Verified

129 Haskell self-tests, a 15-entry differential corpus, and a cross-language check (JS interpreter == JS VM == Haskell expected).

Quick start

let rec fib = fn n => if n < 2 then n
               else fib (n - 1) + fib (n - 2)
in fib 25

The pipeline is lex -> parse -> infer (optional) -> eval, or -> compile -> vm. The CLI dispatches both paths; the playground offers the buttons for each stage.

Example

let rec map = fn f xs =>
  if isNil xs then []
  else cons (f (head xs)) (map f (tail xs))
in map (fn x => x * x) [1, 2, 3, 4]

prints [1, 4, 9, 16] on every backend: interpreter, VM, and playground.
