Shaftcast

A first-person raycasting engine that renders a pseudo-3D, Wolfenstein-style view straight into your terminal — DDA ray casting, ASCII depth shading, per-tile textures, a minimap overlay, and first-person movement, using nothing but the Python standard library.

▶ Run it: python3 -m shaftcast

DDA raycasting

One ray per screen column marches cell-by-cell through the grid and scales each wall slice's height by its distance for convincing depth.

ASCII shading

Walls fade with distance through a #%+~.-style ramp; side walls dim, and each wall character can carry its own texture.

Zero dependencies

Only argparse, math, shutil, sys, time (and termios on POSIX). No assets, no GPU, no install step.

Running it

Clone the repo and run from the repository root (Python 3.8+):

# Interactive first-person mode (needs a real terminal)
python3 -m shaftcast

# Render one frame and exit
python3 -m shaftcast --frames 1

# Generate a random perfect maze (deterministic with --seed)
python3 -m shaftcast --maze 21x31 --seed 42

# Load a map file with a minimap overlay
python3 -m shaftcast --map shaftcast/examples/courtyard.map --minimap

Run modes

  • Interactive — selected when stdin and stdout are TTYs: raw termios keypresses, per-frame redraw, hidden cursor.
  • Autopilot — --autopilot turns the camera on its own; Ctrl-C stops it.
  • Frame dump — --frames N prints N frames with header lines, perfect for piping, diffs, and tests. Fully piped output dumps one frame automatically so the command never hangs.

Running the tests

python3 -m unittest discover -s shaftcast/tests

49 tests cover map parsing, maze generation, camera math, DDA ray casting, shading, frame rendering, and the CLI surface.

Map format

A map is a plain-text grid, one character per cell, one row per line:

###########
#.........#
#...###...#
#...#.#...#
#...###...#
#....>....#
#.........#
###########
CharacterMeaning
#Wall with the default brick ramp.
%, =, +, *, $, @, P, ...Wall with its own per-tile ramp.
., , ,, -, _Empty floor.
@ / >Player spawn, facing east.
<Player spawn, facing west.
^Player spawn, facing north.
vPlayer spawn, facing south.

Exactly one player spawn is required; rows are padded to a common width automatically; cells outside the grid are walls; lines starting with # (and blank lines) are comments. Two example maps ship in shaftcast/examples/: small-room.map and courtyard.map.

How it works

1. The DDA ray cast

For each screen column x, the ray direction is the camera direction plus the camera plane scaled by 2*x/width - 1, so the screen edges spread the field of view. The ray marches through the grid with the DDA, advancing whichever of sideX/sideY is smaller until it enters a wall cell. The perpendicular distance gives the depth: lineHeight = height / perp, drawn centered on the horizon.

2. ASCII shading

Wall slices are drawn glyph-per-row from a luminance ramp (# bright to . dark) indexed by the normalized distance; y-side hits are pushed toward the dark end. Per-tile textures give each wall character its own ramp. Ceiling/floor fills use an approximate row-distance gradient unless disabled with --fill none.

3. Movement and collision

WASD and arrow/Q-E input map to world deltas via the camera's direction and perpendicular vectors. Movement checks the X and Y axes independently, so the camera slides along walls; turning rotates the direction and camera plane together.

4. Input handling

An incremental escape-sequence parser keeps arrow keys split across reads from corrupting the stream, and held keys use a short timeout so movement stops cleanly when released.

Design notes

  • Pure core — map parsing, ray casting, shading, and frame rendering are pure functions with no terminal side effects, so they are trivially testable and reusable.
  • Per-axis movement — wall sliding falls out naturally from checking each movement axis independently.
  • Robust input — incremental escape-sequence parsing and held-key timeouts keep the interactive loop reliable.
  • Reproducible mazes — --seed makes every generated maze repeatable, keeping tests deterministic too.
