Maze Chase (Rust)

An original maze-chase game in Rust: one deterministic engine with three full publication layers (terminal, desktop, browser). You are Rill, a pond frog; outrun the four wardens, clear every crumb, and turn the tables with a sunseed.

Status: playable on Linux, macOS, and Windows; release packaging now covers Linux deb/rpm/tarballs, a per-user Windows installer and zip, and a macOS app, dmg, and tarball (unsigned), with native per-OS release verification tracked by #582. Measured terminal compatibility with committed evidence lives in docs/terminal-compat.md; verified so far: one workspace suite covers the engine and all three layers: 594 tests across 63 targets (594 passed, 0 failed in the 2026-10-22 sound-overhaul run; the earlier Tester final rerun at 61f96564 recorded 582/0), plus the pre-Pondwake 398-passed macOS and 374-passed Windows native passes (41 targets each; fresh per-OS reruns are in the final sign-off), and the 19-row maze-chase-verify harness passes with the golden replay intact on Linux in this tree, with the macOS and Windows passes recorded at the pre-Pondwake identity commit and fresh per-OS reruns in the final sign-off. The identity system is original and tested: sprite glyphs with shape-distinct wardens, three contrast-checked themes, every engine event routed to an audio cue with five original tunes, and difficulty/keymap/settings with honest engine presets. The terminal layer plays the full hunt fullscreen: Kitty pixel graphics, Sixel pixels after a live probe, 24-bit and 16-color cell tiers with watchdog auto-degrade, live resize, title/help/scores/settings/key-rebind/pause surfaces, machine high scores, and BEL-plus-ticker sound. Run it with cargo run --release -p maze-chase-terminal inside maze-chase/; the terminal guide covers install, controls, tiers, and troubleshooting. The desktop layer plays the same hunt windowed or fullscreen: shared-raster board pixels, keyboard plus gamepad with remap screens, audio sliders, shared machine scores, per-OS packaging, and a --probe screenshot mode. Run it with cargo run --release -p maze-chase-desktop; the desktop guide covers install, controls, gamepads, and packaging. The browser layer plays the same hunt in a tab: canvas board at bitmap density, keyboard plus swipe plus d-pad, DPR-aware resize, WebAudio sound from the crate's own data, localStorage scores and settings, and node plus headless-chromium E2E. Play in your browser See the browser guide, the measured release scoreboard, and the feature matrix.

Layers

The engine they share hunts headless and verified (cargo run --bin maze-chase-verify inside maze-chase/): four personalities on a reversing wave clock, pathing eyes, relishes, pursuer stages, and four mode rulesets. All three layers run from source, and the release guide covers packages, checksums, install, upgrade, and uninstall; the binaries are unsigned.

  • Terminal: Linux deb/rpm/tarball plus a Windows zip, fullscreen canvas, Kitty/Sixel/Unicode tiers with auto-degrade, dynamic resize. See the terminal guide.
  • Desktop: windowed plus fullscreen GUI on the shared renderer core, keyboard plus gamepad with remap, audio sliders, shared machine scores, native packages (Linux deb/rpm/tarball, per-user Windows installer plus zip, macOS app/dmg/tarball), HiDPI-aware bounded rendering. See the desktop guide.
  • Browser: play in your browser: the same hunt as WebAssembly with keyboard plus touch, DPR-aware canvas, and WebAudio sound. See the browser guide.
