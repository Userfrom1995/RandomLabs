Maze Chase (Rust)

An original maze-chase game in Rust: one deterministic engine with three full publication layers (terminal, desktop, browser). You are Pip, a hungry courier lantern; outrun the four wardens, clear every crumb, and turn the tables with a sunseed.

Status: released and verified across Linux, macOS, and Windows. One workspace suite covers the engine and all three layers: 407 tests across 45 targets green on the release machine, 398 passed and 0 failed on the native macOS pass, 374 passed and 0 failed on the native Windows pass, and the 19-row maze-chase-verify harness passes with the golden replay intact on all three operating systems. The identity system is original and tested: sprite glyphs with shape-distinct wardens, three contrast-checked themes, every engine event routed to an audio cue with five original tunes, and difficulty/keymap/settings with honest engine presets. The terminal layer plays the full hunt fullscreen: Kitty pixel graphics, Sixel pixels after a live probe, 24-bit and 16-color cell tiers with watchdog auto-degrade, live resize, title/help/scores/settings/key-rebind/pause surfaces, machine high scores, and BEL-plus-ticker sound. Run it with cargo run --release -p maze-chase-terminal inside maze-chase/; the terminal guide covers install, controls, tiers, and troubleshooting. The desktop layer plays the same hunt windowed or fullscreen: shared-raster board pixels, keyboard plus gamepad with remap screens, audio sliders, shared machine scores, per-OS packaging, and a --probe screenshot mode. Run it with cargo run --release -p maze-chase-desktop; the desktop guide covers install, controls, gamepads, and packaging. The browser layer plays the same hunt in a tab: canvas board at bitmap density, keyboard plus swipe plus d-pad, DPR-aware resize, WebAudio sound from the crate's own data, localStorage scores and settings, and node plus headless-chromium E2E. Play in your browser See the browser guide, the measured release scoreboard, and the feature matrix.

Layers

The engine they share hunts headless and verified (cargo run --bin maze-chase-verify inside maze-chase/): four personalities on a reversing wave clock, pathing eyes, relishes, pursuer stages, and four mode rulesets. All three layers below ship in the verified release.

  • Terminal (shipped): installable package, fullscreen canvas, Kitty/Sixel/Unicode tiers with auto-degrade, dynamic resize. See the terminal guide.
  • Desktop (shipped): windowed plus fullscreen GUI on the shared renderer core, keyboard plus gamepad with remap, audio sliders, shared machine scores, per-OS packaging (Linux tarball, Windows zip, macOS app bundle). See the desktop guide.
  • Browser (shipped): play in your browser: the same hunt as WebAssembly with keyboard plus touch, DPR-aware canvas, and WebAudio sound. See the browser guide.
