Verify a download

The release publishes one SHA256SUMS.txt for the complete artifact set. Check the files before you run them:

# Linux
sha256sum -c SHA256SUMS.txt

# macOS
shasum -a 256 -c SHA256SUMS.txt

# Windows PowerShell (one file at a time)
Get-FileHash -Algorithm SHA256 .\maze-chase-terminal-0.1.0-windows-x86_64.zip

The binaries are unsigned. Windows SmartScreen and macOS Gatekeeper warn on first launch; those prompts are expected and are not a signature claim. See Releases for the current version and notes.

System requirements

Browser

A modern browser with WebAssembly, Canvas, and WebAudio. Keyboard and touch controls. No install, no account, no network calls after the page and its engine load.

Terminal

A host matching the artifact architecture: Linux x86_64 packages are staged for this tree, Windows artifacts are x86_64, and macOS artifacts name their architecture. Builds for other architectures use the same scripts on a matching host. At least 62 columns by 35 rows; Kitty graphics, Sixel, and truecolor or legacy cell terminals are supported. See Compatibility.

Desktop

A windowing session, audio output, and a keyboard. Linux builds need ALSA and udev at build time; Windows and macOS use the system audio and window APIs. Gamepads are optional.

Saved data

Settings and scores live in ~/.maze-chase (%USERPROFILE%\.maze-chase on Windows). The browser uses localStorage. Nothing leaves your machine.

Build from source now

Every layer builds from a clean checkout with stable Rust 1.89 or newer. Linux packages can be staged today; the native macOS and Windows packaging scripts run on their own hosts. The full commands, toolchain pins, and reproducibility contract live in the release guide.

cd maze-chase
cargo test --workspace --locked
cargo run --release --locked --bin maze-chase-verify
cargo build --release --locked -p maze-chase-terminal
cargo build --release --locked -p maze-chase-desktop
cargo build --release --locked --target wasm32-unknown-unknown -p maze-chase-web
cp target/wasm32-unknown-unknown/release/maze_chase_web.wasm web/maze-chase.wasm
