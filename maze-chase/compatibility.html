Compatibility

Where the hunt runs

The browser build runs in any modern browser. The terminal layer detects its graphics tier at launch and degrades to cells when a richer protocol is not available. This page separates what has been executed and recorded from what is still waiting for its host.

How to read this page. A verified row is a recorded session from the compatibility harness: the game boots, plays, resizes, pauses, and exits, and the evidence bundle and screenshots are committed with the tree; the raw transcript stays a host artifact. The executed rows below ran on Linux on 2026-10-28 against the published maze-chase-v0.1.0-rc.1 terminal binary from tag commit 11a0037b with SHA-256 9f6cd45a. Rows marked awaiting host have not been run and are not claimed.

Graphics tiers

kitty-graphics

The richest tier. The board and sprite atlas transmit as PNG once per change, and moving sprites ride as placements with explicit stacking. Enables the full density and effect set.

sixel

A 64-color quantized raster path for terminals such as xterm in VT340 mode. Paced with byte-rate backpressure and a cell fallback for frames that exceed its budget.

truecolor-cells

Blocks of Unicode half-cells with 24-bit color. No image protocol is needed, so this tier works in most modern terminals.

legacy-cells

The widest fallback. 256-color half-cell rendering keeps the maze, actors, and HUD readable in a plain terminal.

Detection uses environment evidence and a bounded live probe. An unidentifiable terminal is probed; if it does not answer, the game stays on cells. Kitty keyboard enhancement is requested when available, and keys typed during the probe are replayed, never swallowed.

Browser support

The browser layer is verified by an automated headless Chromium suite: boot with zero console errors, a started run, real key input, pause and resume, touch swipes, and a mobile viewport at 390 by 844 and 320 by 480. Chromium-based desktop and mobile browsers are the signed shape. Firefox and Safari use the same standard WebAssembly, Canvas, and WebAudio APIs and are expected to work, but they are not yet in the signed matrix.

The canvas keeps a 280 px CSS minimum; below that the board clips centered instead of reflowing. Touch controls use a 24 px swipe deadzone and an on-screen direction pad on coarse pointers. There is no gamepad API on the web layer by design: keyboard plus touch is the full control scheme.

Desktop support

The desktop window is exercised on Linux, including headless render and Xvfb probes, fullscreen toggling, resize and HiDPI handling, and gamepad polling. Linux deb, rpm, and tarball packages are built and smoke-tested with their uninstall paths. The Windows installer and zip and the macOS app and dmg were built and smoked by their native release jobs in release run 41080938033 and are published in the rc.2 prerelease; the terminal and Windows binaries are unsigned, and the macOS app is ad-hoc signed. No cross-OS relabel is used. See Downloads for current artifact status.

Known limitations

  • The terminal event source holds an unrecognized private CSI sequence until a completion byte arrives, so a malformed escape can delay key delivery. This is documented in the terminal guide and pinned by a regression test.
  • The published rc.2 terminal and Windows binaries are unsigned. The macOS app is ad-hoc signed, passes codesign --verify --deep --strict, and is not notarized; a quarantined download shows the unidentified-developer dialog, not the damaged-app dialog. On macOS 15 and later, approve it in System Settings > Privacy & Security > Security > Open Anyway. The earlier rc.1 app is unchanged at tag commit 11a0037b; it fails code-signature verification and opens as damaged. SmartScreen and unidentified-developer warnings are expected on first launch.
  • The video watchdog watches the frame write path. A terminal that silently mis-composites cannot be detected; explicit stacking layers are used so overlapping sprites cannot depend on a terminal's tie-break.
  • Light and dark terminal backgrounds render the same theme canvas. A terminal that forces its own background color over painted cells is outside the verified rows.

Report a terminal or browser that is missing: open an issue with the terminal name and version, the observed tier, and a screenshot. The harness scripts are in tools/compat/.
