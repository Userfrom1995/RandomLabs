Install

One game, three ways to play

Open the browser build with no install, or take the same deterministic engine to a terminal or a native window. Settings and scores move with you through the shared ~/.maze-chase directory on native layers.

Browser

The WebAssembly build is the complete game: no account, no download, and no gameplay code in the page. Open the game page and press Start.

To run it from a checkout instead, serve the directory over HTTP. Browsers refuse to fetch .wasm over file://:

cd maze-chase
python3 -m http.server 8000   # Windows: python -m http.server 8000
# Open http://localhost:8000/index.html

To rebuild the engine blob after changing Rust code:

rustup target add wasm32-unknown-unknown
cargo build --release --locked --target wasm32-unknown-unknown -p maze-chase-web
cp target/wasm32-unknown-unknown/release/maze_chase_web.wasm web/maze-chase.wasm

Terminal game

The terminal layer needs no window system. At least 62 columns by 35 rows are required; Kitty graphics, Sixel, truecolor cells, and legacy cells are detected automatically. The full matrix is on Compatibility.

Linux

Debian or Ubuntu, from a staged deb:

sudo apt install ./maze-chase-terminal_<version>_<arch>.deb
maze-chase-terminal --version
sudo apt remove maze-chase-terminal

Fedora or RHEL, from a staged rpm:

sudo dnf install ./maze-chase-terminal-<version>-1.<arch>.rpm
maze-chase-terminal --version
sudo dnf remove maze-chase-terminal

The Linux binaries are built against glibc 2.39. Supported hosts are Ubuntu 24.04+, Debian 13+, Fedora 40+, and RHEL 10+; RHEL/Rocky 9 and older Debian/Ubuntu releases are below the floor and are not supported. Use apt/dnf so the declared dependencies resolve; if an earlier dpkg -i reported missing dependencies, run sudo apt-get -f install. The RPM keeps Release: 1 for every candidate of the same workspace version, so replacing one candidate with another needs sudo dnf reinstall ./<newer rpm> or sudo rpm -U --replacepkgs <newer rpm>; a bare sudo rpm -U refuses the identical NEVRA.

The tarball installs per-user without root by default:

mkdir maze-chase-terminal
tar -xzf maze-chase-terminal-<version>-linux-<arch>.tar.gz -C maze-chase-terminal
cd maze-chase-terminal
./install-linux.sh                                  # installs into $HOME/.local
sudo ./install-linux.sh --prefix /opt/maze-chase    # system-wide
./uninstall-linux.sh                                # removes the user install
sudo ./uninstall-linux.sh --prefix /opt/maze-chase  # removes the /opt install

Windows

Extract maze-chase-terminal-<version>-windows-x86_64.zip and run maze-chase-terminal.exe from Windows Terminal or conhost. Windows Terminal with a truecolor profile is the recommended host. Delete the extracted folder to uninstall.

macOS

Extract the terminal tarball and run its install-linux.sh (the script is portable), or run the binary in place. Remove the installed binary and launch doc with uninstall-linux.sh, adding --purge-config to remove saved settings.

Desktop app

The desktop layer adds a windowed or fullscreen presentation, a side HUD, gamepad input, and pixel menus. It shares settings and scores with the terminal layer.

Linux

sudo apt install ./maze-chase-desktop_<version>_<arch>.deb
# or: sudo dnf install ./maze-chase-desktop-<version>-1.<arch>.rpm
maze-chase-desktop --version
sudo apt remove maze-chase-desktop
# or: sudo dnf remove maze-chase-desktop

The deb and rpm declare the desktop runtime dependencies and install them through apt/dnf: ALSA, udev, xkbcommon including the X11 backend, and the X11 libraries winit loads (libxcursor1 libxrandr2 libxi6 libxinerama1 on Debian/Ubuntu; libXcursor libXrandr libXi libXinerama on Fedora/RHEL). The same glibc 2.39 floor applies. The package installs /usr/bin/maze-chase-desktop, the desktop entry, and the icon. The tarball uses the same install-linux.sh / uninstall-linux.sh pair as the terminal layer and needs the same runtime libraries installed.

Windows

Run maze-chase-desktop-<version>-windows-x86_64-setup.exe. The installer is per-user, asks for no administrator rights, and offers Start Menu and optional desktop shortcuts. The zip is the portable option: extract it and run maze-chase-desktop.exe. SmartScreen may warn because the binary is unsigned; choose More info, then Run anyway.

macOS

Open the dmg and drag Maze Chase.app to Applications, or extract the tarball and copy the app there. The rc.2 app bundle is ad-hoc signed and passes codesign --verify --deep --strict, so a quarantined download shows the unidentified-developer dialog, not the damaged-app dialog. It is not notarized and has no Apple Developer ID. On macOS 15 and later, approve it in System Settings > Privacy & Security > Security > Open Anyway; a right-click Open can still end at the Not Opened dialog with Done. The earlier rc.1 app is unchanged at tag commit 11a0037b; it fails code-signature verification and opens as damaged, so install rc.2 instead. The dmg and tarball embed the desktop guide (docs/desktop.md) as README-desktop.md from the rc.2 tag, and that published copy is immutable; the corrected text ships in the next candidate. Upgrade by replacing the app; uninstall by moving it to the Bin.

Launch and options

maze-chase-terminal [OPTIONS]
maze-chase-desktop [OPTIONS]

--dir <path>                 config and scores directory (default ~/.maze-chase)
--version / --help
# desktop also:
--fullscreen                 start fullscreen
--no-pad                     ignore gamepads
--probe <frames> <shot.ppm>  render frames, save a screenshot, exit

In the desktop window, F toggles borderless fullscreen. A window too small for scale 1 shows a too-small card instead of a clipped board.

Upgrade and remove

Upgrade a deb with sudo apt install ./<newer deb> (add --reinstall when apt already considers the same version current) and an rpm with sudo dnf install ./<newer rpm>. Candidate RPMs of the same workspace version share the 0.1.0-1 NEVRA, so replacing one candidate with another needs sudo dnf reinstall ./<newer rpm> or sudo rpm -U --replacepkgs <newer rpm>; a bare sudo rpm -U refuses an identical NEVRA. On Windows, run the newer setup over the old install; the zip is replaced by extracting the new version. Replace the macOS app with the new one.

Uninstalling keeps settings and scores by default. Both layers store them in ~/.maze-chase (%USERPROFILE%\.maze-chase on Windows); pass --purge-config to the install scripts, or remove that directory, to clear them. The Windows installer keeps user data on uninstall so an upgrade or reinstall preserves progress.

Build from source

Stable Rust 1.89 or newer is required. Linux desktop builds also need ALSA and udev headers plus the xkbcommon and X11 runtime libraries. The packaged deb/rpm declare these runtime dependencies; a source or tarball install needs them present:

sudo apt-get install libasound2-dev libudev-dev libxkbcommon0 libxkbcommon-x11-0 libxcursor1 libxrandr2 libxi6 libxinerama1
cd maze-chase
cargo test --workspace --locked
cargo run --release --locked --bin maze-chase-verify
cargo build --release --locked -p maze-chase-terminal
cargo build --release --locked -p maze-chase-desktop

The full toolchain pins, native packaging commands, reproducibility contract, and clean-checkout checklist live in the release guide. Native macOS and Windows packages are built on their own hosts; no artifact is relabeled across operating systems.
