Frame budgets (design, with measured anchors)

  • Engine tick: 0.8 us measured (above). At 120 Hz the simulation costs about 0.01% of the frame budget; every layer can spend its frame on presentation.
  • Terminal: 60 fps loop with watchdog auto-degrade (measured implicitly by the headless layout sweep and the tier ladder tests; the CI terminal tests claim no wall-clock FPS because CI terminals have no comparable clock; the compatibility harness measures it on a real terminal).
  • Desktop: fixed 120 Hz session matching the engine timestep; Xvfb --probe run rendered real titled frames to PPM.
  • Browser: 60 FPS live in the CDP run (release evidence); the canvas composer mirrors the shared 8-ppt reference raster with a frame-determinism test (web::video, web::bridge hostile probes).
