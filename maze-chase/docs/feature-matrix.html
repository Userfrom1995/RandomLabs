Feature-Completeness Matrix

Shared binding tracker for every mechanic across the one engine and the three publication layers. One row per mechanic; columns name the engine module, each layer's status, and the test proof. Kept current with every change.

Status words: done (implemented, tested, verified), planned (scoped, no code yet), degraded (documented capability fallback, never silent), n/a (genuinely not applicable to that layer). By the zero-stub rule no UI layout ever pretends a planned row works.

Rules

  • Every row needs test proof; a row without a named test file stays planned.
  • Any gameplay branch inside a layer crate is a blocking review finding; layers map input to TickInput and render Game state plus GameEvents.
  • Unavoidable capability gaps become degraded with a documented fallback path, never silent drops.
