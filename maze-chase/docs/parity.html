#552 parity checklist

What the Rust build had to prove before the #552 Python reference game (pacman/, issue #552) could be retired. Every row below names its evidence: the simulation and layer rows are signed from the in-repo verify and test suites, the per-layer E2E rows record this tree's Linux runs plus the pre-Pondwake macOS and Windows runs (with fresh per-OS reruns tracked in the final sign-off), and the sound row records its remaining real-speaker review boundary explicitly instead of claiming it. Retirement itself was a separate, explicit step that executed after this verified release landed: nothing in pacman/ is touched by any build or packaging script here, and the Python game stayed functional through the whole migration.

Rule values below are feel references re-expressed as original Rust tables (crates/engine/src/tuning.rs) under the clean-room rules in docs/legal.md. The maze itself is intentionally NOT a copy: "Ember Warren" (levels/ember-warren.maze) is original geometry with its own counts (445 crumbs + 4 sunseeds vs the reference 282 + 4) and its own authorship log (docs/identity.md). Parity means the rules and feel match; the map is ours.

Native proof record

The per-layer E2E and packaged-artifact rows above are signed on Linux on this tree; the macOS and Windows runs below are the pre-Pondwake record, with fresh reruns tracked in the final sign-off. The measured numbers sit in the dated sections of scoreboard.md.

  • macOS (tester run 39068848280, macOS 26.6.2 arm64, vehicle PR #631 merged): workspace 398 passed / 0 failed across 41 targets, maze-chase-verify 19/19 with the golden digest intact, terminal PTY E2E 28/28 (probe window, tier precedence, resize recovery, corrupt-config boot), desktop --probe plus an osascript-driven GUI session, the staged .app bundle (probe exit 0, binary hash matching the release build), and a byte-identical wasm rebuild (sha256 5ec2a05af55f...).
  • Windows (tester run 39068849150, Windows Server 2025, Git Bash plus real ConPTY, vehicle PR #632 merged): workspace 374 passed / 0 failed across 41 targets, maze-chase-verify 19/19, the full CLI matrix in Git Bash and pwsh, the packaged zip (binary byte-identical to the release build) with a probe PPM byte-identical to the committed reference, web node smokes, and CDP browser E2E. That pass found three defects (terminal Release-key double fire, desktop --probe option order, CRLF wasm drift); all three fixes merged with regression contracts executed red on the pre-fix head and green on the fixed head by the independent Quality Council round (approve-eval 9.8/10).
  • Linux (pre-Pondwake release pass): 407 tests passed / 0 failed across 45 targets, maze-chase-verify 19/19, terminal and desktop tarballs staged, installed to a scratch prefix, and probed, node smokes, and real-browser CDP E2E all green.
