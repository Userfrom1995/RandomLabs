Prism

A lossless image codec in C++17 - Squeeze + MA-tree, beating JPEG XL on Kodak.

Source Try the demo

M0 - bit-exact codec

Format-agnostic front-end (PNG/JPEG/BMP/PPM via stb_image), reversible YCoCg-R, MED prediction, context-modeled entropy, PRSM container with CRC32 gates. Round-trip and corruption-rejection fuzz gate.

cmake -S prism -B build && cmake --build build -j
./build/prism enc in.png out.prism --effort 4
./build/prism dec out.prism out.ppm
./build/prism fuzz --iters 1000
