Prism

A lossless image codec written from scratch, measured against the state of the art.

Reversible color decorrelation, a MED/GAP predictor bank with MA-tree context, context-modeled entropy, and a corruption-rejecting PRSM container - every byte verified round-trip exact. Built as the successor to Obsidian and benchmarked head-to-head with PNG, WebP, JPEG-LS, and JPEG XL on the Kodak dataset, with every negative result committed, not buried.

How it works

Six stages, one invariant

The hard rule that gates everything: decode(encode(x)) equals x, byte for byte, measured at efforts 0/4/7. Corruption is rejected, never mis-decoded.

stage 1ColorReversible decorrelation (YCoCg-R and five adopted rotations) chosen by measured coded bytes.
stage 2SqueezeMulti-resolution JPEG XL CDC lifting (true integer H-then-V passes), adopted per plane when coded bytes win.
stage 3PredictionMED/GAP predictor bank chosen by measured coded bytes.
stage 4ContextMA decision-tree context modeling over spatial residual features, accepted only when trial encodes win.
stage 5EntropyContext-modeled binary adaptation (343 causal residual-DIFF contexts on flat planes; per-leaf models only when the stage 4 tree trial wins) entropy-coded by a 32-bit FIFO adaptive binary range coder (rANS is retained for the static effort-0 path); zero-flag/sign/gamma-style magnitude binarization.
stage 6ContainerPRSM magic, LE header, CRC-checked model blob and payload. Hard rejection on corruption.

Why it stopped there

The single-pass architecture has a hard, reproducible ceiling. Across the research program, 49+ mechanisms were measured over 7+ benchmark programs and no legitimate mechanism class remained unmeasured. The full negative ledger is committed on main, and every build branch is retained - nothing was deleted, so every claim here is re-checkable.

Successor to Obsidian

Obsidian (issue #68, archived) plateaued at 9.5208 bpp. Prism was built to close the redundancy-class gap to JPEG XL by coupling multi-resolution Squeeze with a meta-adaptive MA-tree context model, behind a bit-exact round-trip invariant from day one. The complete build record lives in issue #130.

Quick start

Build, encode, verify

CMake and a C++17 compiler (the first configure fetches GoogleTest unless libgtest-dev is installed). PNG/JPEG/BMP/TGA/HDR input via stb_image; WebP and TIFF behind CMake options. The fuzz gate proves the round-trip invariant locally.

build
cmake -S prism -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
round-trip proof
./build/prism fuzz --iters 1000
# encode/decode round trips (corruption rejection is asserted by the ctest run above)
encode and decode
./build/prism enc in.png out.prism --effort 4
./build/prism dec out.prism out.ppm
./build/prism info out.prism
benchmark on Kodak
prism/benchmarks/run_kodak.sh --effort 4 \
  --kodak prism/benchmarks/data/kodak
python3 prism/benchmarks/aggregate.py
# provision the Kodak-24 corpus at prism/benchmarks/data/kodak first: the tracked
# symlink dangles in a fresh checkout (see prism/docs/benchmark-methodology.md);
# without a corpus the script benchmarks a 2-image synthetic probe instead
