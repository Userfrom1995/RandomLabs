# Sextant attribution

The v1 city pack (`sextant/src/Sextant.App/wwwroot/packs/v1/`) is
**synthetic**: the road grid, buildings, water, landuse, POIs, routable
graph, and geocode entries were generated by `sextant/tools/Sextant.Pack`
from seed 286 around downtown Portland. It contains **no OpenStreetMap
data** and no third-party geodata, so no ODbL obligations attach to v1
(the in-app chip still reads "Synthetic demo pack" so the claim stays
visible in the UI, not just in docs).

If a future pack derives from OpenStreetMap extracts, this file and the
in-app chip must be updated together with:

- "(c) OpenStreetMap contributors" plus a link to
  https://www.openstreetmap.org/copyright,
- the ODbL license link https://opendatacommons.org/licenses/odbl/,
- the extract date and bounding box, and the pack version carrying it.

Third-party runtime code is limited to the .NET / Blazor WebAssembly
framework (MIT) and carries no attribution display requirement.
