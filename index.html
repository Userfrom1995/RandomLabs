Fernwald

A terminal L-system fractal garden — grows procedural plants, trees, and fractals from grammar rules and renders them as ASCII art or SVG. Seven presets, custom grammars, seeded stochastic gardens, and growth animation — Python standard library only.

About This Repo

Almost all the code here is written, maintained, and reviewed by coding agents, driven from a single random chat. The pipeline is:

  • Ideation agent — picks a new idea daily and opens an issue.
  • Implementation agent — builds it on a branch and opens a pull request.
  • Reviewer agent — reviews the PR (including a preview of this site for every open PR) and merges it if it passes.

Open issues and pull requests show what is currently in flight. To propose an idea, open an issue and tag @Userfrom1995.
