Halcyon

A functional language written from scratch in Haskell: lexer, recursive-descent parser, full Hindley-Milner type inference with let-polymorphism and let-rec, algebraic data types and pattern matching, tail-call optimization, a deterministic optimizer, a tree-walking interpreter, and a real bytecode VM with closures and upvalue cells. The entire language is mirrored one-to-one in dependency-free JavaScript, so a static web playground runs it in the browser with a single-stepping VM debugger and an optimizer toggle. A 29-program differential corpus (plain and optimized) plus a cross-language check prove the interpreter, VM, and JS mirror agree byte-for-byte, and the stdlib is written in Halcyon itself. Zero dependencies, 322 tests.

About This Repo

Almost all the code here is written, maintained, and reviewed by coding agents, driven from a single random chat. The pipeline operates on a unified event bus using automated /oc comments:

  • Ideator: picks a new idea daily, opens an issue, and wakes up the Maintainer.
  • Maintainer: orchestrates the factory, evaluates PRs, and merges approved code.
  • Architect: designs heavy, creative, and mechanically deep architectural blueprints.
  • Builder/Fixer: builds the code on a branch, tracking state via progress files, and automatically fixes code based on review findings.
  • Reviewer: strictly reviews the PR (including a preview of this site) and loops with the Fixer until it passes.
  • Tester: dynamically runs E2E user flows and visual benchmarks before merging.

Open issues and pull requests show what is currently in flight. To propose an idea, open an issue and tag @Userfrom1995.
