Gambit

A UCI chess engine written from scratch in C++17: bitboard board representation, perft-verified legal move generation, and a negamax alpha-beta search with iterative deepening and a transposition table. Plays in the terminal or speaks UCI to any chess GUI.

Open the project →

Bitboards

64-bit integers for the board: one per piece type and color plus occupancy. Precomputed knight, king, and pawn attacks; ray-based sliding attacks with blocker detection.

Legal move generation

All pieces, castling, en passant, and promotion, filtered for king safety. Verified against the standard perft suite: start position to depth 5, kiwipete, and positions 3-6.

Search

Negamax alpha-beta with quiescence, LMR, killers, TT move ordering, and PV tracking. Iterative deepening with time management.

UCI + CLI

A standard UCI loop for GUIs and a human-facing terminal mode: a Unicode board, SAN input with hints and takebacks, perft, divide, and analyze.

Try it

cd gambit
make                 # builds ./gambit
make test            # builds and runs the test suite (ALL PASS)

./gambit play --depth 12        # play white against the engine
./gambit analyze 12             # analyze the start position to depth 12
./gambit perft 5                # verify move generation (4,865,609 nodes)
./gambit divide 3               # per-move perft breakdown
./gambit                        # UCI protocol mode (for chess GUIs)

CLI commands

CommandWhat it does
gambit (default)Run the UCI protocol loop for chess GUIs.
gambit play [--black] [--depth N] [--movetime MS]Play a full game against the engine.
gambit analyze [depth] [fen]Search a position and print best move, score, PV.
gambit perft [depth] [fen]Count nodes and move categories at a depth.
gambit divide [depth] [fen]Perft with a per-move breakdown.
gambit testRun the built-in test suite.
gambit helpShow usage.

The default FEN is the standard start position. Requires a C++17 compiler; no external dependencies.

How it works

  • Move encoding. Each move is a 32-bit word: from and to squares, promotion piece, a flag (normal, double push, en passant, castle, promotion), the captured piece type, and the moving piece type.
  • Board model. Six piece-type bitboards, two color bitboards, and an occupancy bitboard, plus side to move, castling rights, the en-passant square, the halfmove clock, and the fullmove number. Zobrist keys update incrementally on every move.
  • Make/unmake. make() updates board, occupancy, key, castling rights, and history in one pass; unmake() restores the previous state exactly. A symmetry test walks every legal move of several positions and confirms FEN and key round-trip.
  • Search loop. Iterative deepening searches depth 1, 2, 3, ... until the target depth or the time budget is reached. Each iteration feeds the previous best move into the transposition table for move ordering. Scores are centipawns; mates report as mate N.
  • Draw detection. Fifty-move rule, threefold repetition via the key history, and insufficient material.

Design choices

  • C++17, no dependencies. Plain standard C++ through a small Makefile; no external libraries.
  • Correctness first. The standard perft suite is the ground truth for the move generator and re-runs on every make test.
  • UCI-compatible. The default mode is a real UCI engine, so Gambit plugs into any chess GUI as well as the terminal.
  • Honest search. No weakening or force-gags; what you see is what the search found.
