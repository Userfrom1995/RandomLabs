    Load order

        Milestone 4 scope

        WAD ecosystem and polish: multi-file load order with map-group replacement and last-wins resources, per-map isolation (one corrupt map never kills the load), DEHACKED surfacing, onboarding plus sample level, loading and error states with the previous level kept running, shareware episode clamp, and an offline service worker pass that preserves the WAD cache. Audio, saves, renderer, and input shipped in M1-M3.

        Milestone 5 scope

        Integration and end-to-end audit: the renderer selector now pins the stored tier instead of re-probing, the full H1-H5 ledger is measured end to end in a real browser (see docs/scoreboard.md and docs/bench-m5.json), and settled desktop plus mobile proofs live at docs/shell-m5-1280.png and docs/shell-m5-390.png (see docs/render-m5.md).
