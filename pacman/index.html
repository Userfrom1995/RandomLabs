Pac-Man Terminal Arcade

A complete Pac-Man arcade experience that runs directly in the terminal: sprite-grade visuals over the Kitty graphics protocol where supported, Sixel coverage, and a Unicode plus truecolor fallback that plays everywhere. All code, mazes, art, and tuning are originals.

Play it

Requires Python 3.11 or newer. No install step; the guaranteed path uses only the standard library (pip install Pillow unlocks the image backends).

python3 pacman/pacman.py --maze-check
python3 pacman/pacman.py --self-check --ticks 2400 --seed 2
python3 pacman/pacman.py --render-check --renderer kitty
python3 pacman/pacman.py --render-bench --frames 60
python3 pacman/pacman.py --play --audio auto

Controls: arrows or WASD move, P pauses, R restarts, Enter confirms, Q quits. Remap with --bind up=k (repeatable); --keys prints the table. Sound follows --audio null|bell|synth|auto, degrading honestly when no system player exists.

Renderers

One scene painter feeds every backend, so the layout matches cell-for-cell: kitty (cached sprite atlas, transmit-once, per-frame placement), sixel (dirty-region raster, 10 fps cap), unicode (synchronized truecolor text, plays everywhere). A watchdog steps down one tier on errors or slow frames. --renderer overrides auto-detection; without Pillow the game degrades honestly to Unicode.
