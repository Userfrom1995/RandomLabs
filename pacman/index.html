Pac-Man Terminal Arcade

A complete Pac-Man arcade experience that runs directly in the terminal: sprite-grade visuals over the Kitty graphics protocol where supported, Sixel coverage, and a Unicode plus truecolor fallback that plays everywhere. All code, mazes, art, and tuning are originals.

Play it

Requires Python 3.11 or newer. No install step; the guaranteed path uses only the standard library (pip install Pillow unlocks the image backends).

python3 pacman/pacman.py --maze-check
python3 pacman/pacman.py --self-check --ticks 2400 --seed 2

Status

Engine core plus ghost AI are live and verified. The deterministic headless simulation plays full levels today: original maze with tunnel and ghost house, buffered tile-center movement, four ghost personalities with scatter/chase waves and fright chains, scoring with extra life, lives with respawn, endless level progression, seeded replays with bit-identical hashes, and a 101-case test suite. The interactive terminal loop with menus and audio is under construction in the open tracking issue.
