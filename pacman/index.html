Pac-Man Terminal Arcade

A complete Pac-Man arcade experience that runs directly in the terminal: sprite-grade visuals over the Kitty graphics protocol where supported, Sixel coverage, and a Unicode plus truecolor fallback that plays everywhere. All code, mazes, art, and tuning are originals.

Play it

Requires Python 3.11 or newer. No install step; the guaranteed path uses only the standard library (pip install Pillow unlocks the image backends).

python3 pacman/pacman.py --maze-check
python3 pacman/pacman.py --self-check --ticks 2400 --seed 2
python3 pacman/pacman.py --render-check --renderer kitty
python3 pacman/pacman.py --render-bench --frames 60
python3 pacman/pacman.py --verify
python3 pacman/pacman.py --scoreboard --frames 60
python3 pacman/pacman.py --modes --themes --levels 8
python3 pacman/pacman.py --layout-check 120x50
python3 pacman/pacman.py --play --mode classic --theme neon --audio auto

Controls: arrows or WASD move, P pauses, R restarts, Enter confirms, Q quits. Remap with --bind up=k (repeatable, persisted with --save-config); --keys prints the table. Sound follows --audio null|bell|synth|auto, degrading honestly when no system player exists. The game fills the whole window as a full-screen canvas (maze plus live dashboards on wide terminals; --layout-check reports the regions); windows below 28x34 get a clear too-small message instead of a garbled maze.

Modes and themes

Four rulesets: classic (standard loop), time-attack (120 seconds on a refilling maze), sprint (one life, no fright, par-time bonus), fright-frenzy (4x fright, slower ghosts). Three original palettes (classic, neon, amber) plus a reduced-flash mode. Fruit ripens twice per level, high scores persist with in-terminal name entry (--scores prints the table), and the endless difficulty ramp is inspectable with --levels N.

Renderers

One scene painter plus a fullscreen composer feeds every backend, so the layout matches cell-for-cell: kitty (cached sprite atlas, transmit-once, per-frame placement), sixel (dirty-region raster, 10 fps cap), unicode (synchronized truecolor text, plays everywhere). A watchdog steps down one tier on errors or slow frames. --renderer overrides auto-detection; without Pillow the game degrades honestly to Unicode.

Scoreboard (reference machine)

Headless full-scene throughput via --scoreboard --frames 60: unicode ~1,118 fps, kitty ~694 fps, sixel ~94 fps; key decode ~2.1M keys/s; simulation ~14 us per tick against the 8,333 us 120 Hz budget. One 28x34 scene painter plus the fullscreen composer feeds every backend, so layouts match cell-for-cell with honest degrade where Pillow is missing. --verify proves the 57-row gameplay, terminal-size, responsive-layout, capability, input, and parity matrix on any machine.
