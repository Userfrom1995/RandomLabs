# Pac-Man Terminal Arcade - Documentation

A complete Pac-Man arcade experience for the terminal: an original deterministic
simulation (maze, ghosts, fruit, modes, replays), a tiered kitty/sixel/unicode
renderer behind an auto-degrading watchdog, and an interactive shell with menus,
scores, and remappable keys. Start with the README quickstart, then prove the
  build with `python3 pacman/pacman.py --verify` (see `verification.md` for the
 82-row report) and compare local throughput with `python3 pacman/pacman.py
--scoreboard --frames 60` (see `scoreboard.md` for the reference numbers).

## Architecture

The system is split into a pure simulation, a string-based presentation layer, and the interactive shell that joins them. The simulation never imports presentation or OS modules, so replays, tests, and benchmarks run identically on every machine.

### Simulation (`src/engine/`)

- `tuning.py` - the single home for every gameplay number: speeds, wave clock, fright curve, scoring chains, fruit tiers, house counters, Elroy stages, mode modifiers. All tables are authored originals with provenance comments. `level_summary()` exposes one row of the endless difficulty ramp for the HUD, CLI, and docs.
- `rng.py` - seeded mulberry32 with forkable named streams, so visual-only changes can never shift simulation hashes. Name mixing uses SHA-256 (never the salted builtin hash), keeping streams identical across processes.
- `maze.py` - the original 28x31 symmetric layout: walls, 282 dots, 4 energizers, a side tunnel row with horizontal wrap, and a central ghost house with a ghosts-only door. Walkability is queried per actor kind; a flood fill proves every pickup is reachable from spawn.
- `actors.py` - continuous tile-unit positions with tile-center movement: instant reversal, buffered perpendicular turns that latch near tile centers with a corner cut, exact halts on tile centers against walls, and tunnel wrapping.
- `game.py` - the fixed 120 Hz state machine: dot, energizer, and fruit pickup, scoring with ghost chains and a one-time extra life, death and respawn sequences, game over with a recorded reason (defeat, timeout, cleared), endless level transitions with maze regeneration, mode clocks (time-attack countdown with maze refill, sprint race clock with par bonus), and per-mode fright rules. Exposes `state_hash()` over a canonical snapshot for determinism proofs.
- `fruit.py` - the bonus-fruit lifecycle: two spawns per level at fixed dot thresholds on the corridor tile below the ghost house, a fixed expiry window, tier points from tuning, and tile pickup. Uses no randomness, so replays stay bit-identical; death or a fresh maze clears uneaten fruit.
- `modes.py` - the four honest rulesets over the classic simulation: classic (standard loop), time-attack (120 seconds on a refilling maze), sprint (one life, no fright, clear fast for a par-time bonus), fright-frenzy (4x fright windows, slower ghosts). Pure modifier functions, so engine, HUD, CLI, and docs always agree; unknown names raise.
- `ghosts.py` - the four ghost roles (direct chaser, ahead ambusher, pincer flanker, shy drifter) with per-corner scatter targets, the scatter/chase wave clock with about-face reversals, fright timing with flashing warning and chain scoring, eye returns that revive at the door, dot-counter plus idle-timeout house exits with a scripted walk-out, tunnel slowdown, and Elroy enrage stages. Collision resolution lives here: frightened hunters are eaten for chain points, active ones cost a life, eyes pass through.
- `replay.py` - input logs plus state hashes: re-running a recording must reproduce the hash bit-for-bit.

### Presentation (`src/render/`)

- `protocol.py` - the `RenderBackend` interface: `init`, `present`, `clear`, `shutdown`, all pure functions returning the exact bytes to write. Tests capture those strings, so terminal behavior is verified without a terminal.
- `framebuffer.py` - the cell grid (glyph plus truecolor fg/bg plus optional sprite id) with dirty-set tracking and magnification spans for multi-cell image placements; per-frame encode cost is O(dirty).
- `scale.py` - the magnification engine: terminal size plus mode (auto, classic, wide, full) to integer 1x/2x factors with a never-raising total function and a raising validator for CLI input.
- `effects.py` - tick-driven animation frames from game counters (mouth, energizer pulse, fruit sparkle, death sequence, fright shimmer, clearing rainbow): pure, single-column, deterministic per tick.
- `layout.py` - the responsive region engine, now scale-aware: given a terminal size plus a magnified maze box it places the maze composition with side panels and strips, reporting fits=False below the box.
- `scene.py` - the parity anchor: paints HUD (score, lives, mode clocks, fruit value), maze (walls in the theme's line style, dots, steady/pulsing energizers), and actors (mouth-animated player, per-personality ghosts, fright shimmer/flash/eyes states, pulsing fruit glyph, death frames, rainbow clearing walls) into one 28x34 FrameBuffer every backend shares. Takes a theme name, a reduced-flash switch that holds steady glyphs everywhere, and an effects switch (off by default, so the legacy reference frame is one flag away).
- `themes.py` - six original palettes (classic, neon, amber, midnight, forest, ember) as plain RGB role dicts, each with a wall-drawing style and a margin chrome pattern; unknown names raise.
- `atlas.py` - the original sprite raster source: Pillow-drawn disc bodies with open and closed wedge mouths and dot eyes, cached by id, PNG-encoded for transmit; raises an actionable error without Pillow instead of guessing. Closed-mouth ids append the registry, so every existing image id is stable.
- `unicode.py` - the reference backend and guaranteed play path: alternate screen, hidden cursor, DEC 2026 synchronized output, only changed cells emitted. Every other backend matches its layout within one cell.
- `kitty.py` - the image backend: atlas transmit once (`a=T`, chunked, quiet mode), cursor-anchored placements (`a=p`) per dirty sprite cell with multi-cell spans for magnified blocks, truecolor text for glyph cells so parity holds, cursor-anchored erases (`a=d,d=c`) before redraws so moved sprites leave no trails.
- `sixel.py` - the raster backend: dirty-region bounding box rasterized (glyphs via the built-in font, sprites pasted from the atlas), quantized to a bounded palette, emitted as band data with run-length compression; a minimum frame interval coalesces faster callers and `present` never sleeps.
- `detect.py` - capability detection: explicit flag beats `PACMAN_RENDERER`, which beats environment heuristics, which fall through to Unicode. Image backends additionally require Pillow and degrade honestly without it.
- `manager.py` - the tier: backend factory plus `TieredRenderer`, which chains the detected choice over the remaining tiers with Unicode always last and steps down on backend errors or two consecutive slow frames. `present` never raises; drops are counted, not hidden.
- `compose.py` - the fullscreen composer: magnified scene blit with image spans, live score/run/progress dashboard, controls-and-legend panel, title and hints strips, themed chrome backgrounds, and fruit sparkles, all from live game data.

### Command line (`src/shell/`)

Every flag maps to working logic: `--maze-check` validates dimensions, counts, and connectivity; `--self-check` runs a greedy BFS autopilot headlessly and prints the score line (ghosts eaten, deaths, fright and wave mode, fruit eaten with points, game-over reason) plus the state hash, honoring `--mode`; `--render-check` paints one scene and presents it through the tiered renderer with byte counts; `--render-bench` prints per-backend present() throughput; `--verify` runs the 82-row gameplay/size/layout/visual/capability/input/controls/parity matrix with a non-zero exit on failure; `--input-bench` reports key-decode throughput and per-tick simulation cost; `--scoreboard` prints the published perf scoreboard for the local machine; `--layout-check` reports the magnification plus canvas regions for a size (live size plus samples by default); `--play` starts the interactive game (refuses cleanly without a tty); `--audio` picks the sound backend with honest synth-to-bell degrade; `--bind` remaps keys with validation and `--keys` prints the table; `--fps` paces the frame loop; `--mode` selects the ruleset; `--theme` plus `--reduced-flash`/`--no-reduced-flash` restyle rendering; `--scale` picks the maze magnification and `--effects`/`--no-effects` toggles animation; `--name` sets the pilot name; `--scores` prints the high-score table (`--scores-file` redirects it); `--modes`, `--themes`, and `--levels N` print the mode list, theme list, and difficulty ramp; `--save-config` persists the effective settings to the config file (`--config-file` redirects it) for the next run. Unset options fall back to the config file, then to defaults. Misuse exits non-zero with a clear error.

### Interactive shell (`src/shell/`)

- `input.py` - the key decoder: arrow keys (CSI and SS3), WASD/vim defaults, Esc for pause, Ctrl-C for quit, Enter/Space for confirm, R for restart, M for session mute, ? for help. Single-char bindings remap through a validated `Keymap` (unknown actions, multi-char keys, and duplicates rejected); trailing partial escape sequences are held for the next read so slow terminals never turn an arrow into a pause.
- `menus.py` - the pure menu model: one navigable item list per screen (title, pause, game-over) with wrapping selection and live labels (the sound item always shows the true on/off state), no I/O, fully headless-testable; every item id maps to a real shell transition.
- `terminal.py` - `RawTerminal`: raw mode on entry, guaranteed restore of the saved attributes on exit (restore failures counted, never masking the loop's exception), non-blocking reads, current-size queries, and a pure minimum-size check that routes undersized windows to a too-small card.
- `screens.py` - title (with mode, theme, and best-score lines), pause, game-over with reason headlines (defeat, time-up, maze-cleared), high-score name entry with live typing, standalone high-score card, fullscreen help card with the live bindings, and too-small cards painted as FrameBuffers in the shared 28x34 geometry, so every backend presents them unchanged; pause, game-over, and entry overlay the live game frame, and title/pause/over render their navigable menus with the selected row highlighted.
- `app.py` - the flow machine (title menu, playing, pause menu, help, scores, high-score name entry, restart, game-over menu, quit to title) plus the frame loop: fixed 120 Hz simulation steps under paced display frames, pause and help genuinely freezing the sim, mode and theme carried from settings into the game and painter, session mute gating every event voice, menu defaults placed so every legacy hotkey (ENTER starts, P resumes, ENTER restarts) keeps working, raw name-entry typing (A-Z 0-9, backspace, Enter to save, Esc to skip, Ctrl-C to quit) that routes around the gameplay keymap, sounds following real game events with throttled dot chirps, renderer shutdown plus audio shutdown in a `finally` that survives loop crashes.
- `audio.py` - pluggable sound: null (counts, silent), bell (BEL chars drained into the frame stream), and synth (original PCM voices, including the two-note fruit chirp, rendered with the stdlib and handed to a real system player on a daemon thread, never blocking; spawn failures counted, never raised). Selection degrades synth to bell when no player exists.
- `scores.py` - the persistent top-10 table in XDG data-dir JSON (`PACMAN_SCORES_FILE` overrides): corrupt or missing files read as empty, unwritable files fail `save()` without raising, names scrubbed to short uppercase ASCII.
- `config.py` - the persistent player config in XDG config-dir JSON (`PACMAN_CONFIG_FILE` overrides): binds, theme, reduced-flash, audio, fps, mode, pilot name, scale mode, effects toggle, version. Every field validated on load with per-field fallback, so a hand-edited file can never break the game.
- `verify.py` - the final verification source of truth: `gameplay_matrix()` (dot/energizer/fright/chain scoring, death/respawn, defeat, level transition, fruit, mode clocks, shell restart/pause flows, tunnel wrap), `size_matrix()` (28x34 fit against six real terminal sizes), `layout_matrix()` (region thresholds, verbatim blits, live dashboards), `visual_matrix()` (magnification ladder, doubled blits with spans, multi-cell kitty placements, mouth/pulse/death/rainbow/sparkle frames, six-theme registry), `capability_matrix()` (detection chain plus honest Pillow degrade), `input_matrix()` (arrows, WASD, controls, partial-escape holds), `controls_matrix()` (mute/help decoding and remaps, session mute silencing, title/pause/over menu navigation and activation, help and scores round-trips, quit to title), `parity_check()` (shared geometry, single-column glyphs, sprite text fallback, clean present on every backend, kitty erase rules, canvas origins), plus `input_bench()`, `render_bench()`, and `canvas_bench()` probes. The CLI, `docs/verification.md`, `docs/scoreboard.md`, and the test suite all read these functions, so they cannot drift apart.

## Verification

Run `python3 -m pytest pacman/tests -q` (408 cases): maze symmetry and reachability, movement feel (buffering, reversal, wall halts, tunnel wrap, wall-collision fuzz), scoring and lives, ghost personalities with wave, fright, house-exit, tunnel, Elroy, eyes, and collision coverage plus a ghost wall-safety fuzz, fruit spawn/expiry/pickup with tier values, all four mode rulesets (sprint no-fright plus par bonus, time-attack refill plus timeout, frenzy fright multiplier, endless ramp sanity), theme painting with reduced-flash steadiness, score-table persistence with corrupt-file survival, config validation with roundtrips, name-entry typing with save/skip/quit, reason headlines, CLI behavior including config persistence, cross-process determinism with golden stream values, tick-rate independence (30 Hz chunks converge with 120 Hz steps), atlas determinism with cache proofs, scene parity across backends with transmit-once and fps-cap proofs, watchdog degradation on errors and slow frames, protocol byte capture, key decoding with partial-escape holds and remap validation, navigable title/pause/over menus with session mute, live help card, and quit-to-title, synth voice rendering with honest audio degrade, terminal teardown on real and fake ttys, menu flows with a scripted headless playthrough, magnification with spans and multi-cell placements, animation frames with determinism pins, and CLI behavior. The seed-1 self-check pin was resurveyed when ghost AI entered the simulation (147 dots in 2400 ticks, with live hunters intercepting the autopilot). Image-backend tests need Pillow; without it they fail honestly (the Unicode path always plays).

Run `python3 pacman/pacman.py --verify` for the 82-row live matrix and
`python3 pacman/pacman.py --scoreboard --frames 60` for the published
numbers; the full writeups are `verification.md` and `scoreboard.md`.
