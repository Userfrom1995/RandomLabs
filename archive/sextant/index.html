Sextant

A from-scratch GIS mapping engine in C# (Blazor WASM). Issue #286.

Run the interactive map

The map is a Blazor WebAssembly app. The compiled bundle is not committed to the repo, so Pages serves this hub; run the live map locally:

dotnet run --project src/Sextant.App
# then open the /map page

What you get: canvas city map (pan/zoom, click-to-route), Mercator/Albers switch, trigram search, A* routes with frontier replay, isochrones, GeoJSON import/export, offline PWA shell.
