pgagroal

client --TCP--> pgagroal pipeline (transaction|session|performance) --SCRAM--> PG backend
             vault users.conf; ev_backend epoll|io_uring

Odyssey

client --TCP--> odyssey workers (1|2|4) --storage_user--> PG backend
             storage + database/user routing rule

pgcat

client --TCP--> pgcat shards (single primary) --SCRAM--> PG backend
             admin_* required; worker_threads 1|5

pgpool-II

client --TCP--> pgpool children --pool_passwd--> PG backend (1:1 child:backend label)
             session-class only; pool_hba equalized arm enables SCRAM
