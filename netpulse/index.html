Netpulse

An honest in-browser network diagnostics tool. Every number carries a source badge; anything the browser sandbox forbids fails closed with an empty state instead of a fabricated gauge.

Scope in this build: connection profile and device context (Overview tab), active quality probes (Quality tab: latency, download, and upload timing over HTTP with probe history), and the DNS toolkit plus opt-in egress identity plus WebRTC inspector (DNS and Identity tab). Traffic observer, monitor dashboard, and export ship in later phases and no panel pretends otherwise. No backend, no CDN, no auto phone-home.

Session events

Timestamped log: connectivity changes, refreshes, session starts. Persisted locally.

    Latency

    Repeated timed HTTP GETs against a cache-busted endpoint. This measures application-layer request timing, not ICMP ping.

    Download throughput

    Sequential cache-busted GETs; real bytes received divided by real elapsed time. Small same-origin files yield small honest numbers.

    Upload throughput

    POSTs a generated random payload to an endpoint you choose and times it. Static file hosts (including this site) reject POST, so leave the field empty only to read why; point it at an echo endpoint you trust to measure.

    Loss approximation and probe history

    Share of this session's probe attempts that failed at the HTTP layer, plus per-run history. This is not ICMP packet loss: browsers cannot send ICMP.

    DNS lookup

    Real DNS answers over DNS-over-HTTPS. Browsers cannot send raw DNS packets, so Netpulse asks a resolver over HTTPS and shows exactly which resolver answered.

    Egress identity

    Opt-in only: nothing is fetched until you click. Asks a third-party echo endpoint for the public IP it sees, labeled with the provider. Useful for VPN and egress checks.

    WebRTC connection inspector

    The closest the sandbox offers to connection analysis: gathers ICE candidates through a public STUN server on a loopback peer connection, then tears it down. Host IPs stay masked as mDNS names by design.
