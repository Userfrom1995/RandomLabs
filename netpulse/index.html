Netpulse

An honest in-browser network diagnostics tool. Every number carries a source badge; anything the browser sandbox forbids fails closed with an empty state instead of a fabricated gauge.

Scope in this build: connection profile and device context (Overview tab). Active probes, DNS toolkit, traffic observer, and export arrive as later phases add their own tabs. No backend, no CDN, no auto phone-home.
