Method notes

Connection profile reads navigator.connection at boot and on its change event; downlink and RTT are browser estimates, not benchmarks. Online state uses navigator.onLine plus window events. Device context is labeled hint-only. The capability gate in js/capabilities.js drives all honest rendering. Quality probes (js/probes.js) time cache-busted HTTP fetches with performance.now() and report median, p95, and jitter over real samples; throughput divides real body bytes by real elapsed time; loss is approximated as the failed share of session probe attempts, never ICMP. Runs persist under netpulse.v1 (50-run cap, explicit clear). Session events persist in localStorage under netpulse.v1 (500-event cap, explicit clear). The DNS toolkit (js/dns.js) fetches real answers over DNS-over-HTTPS from a selectable resolver with per-query timing and raw replies; browsers cannot emit raw DNS packets and the panel says so. Egress identity (js/identity.js) is opt-in only: one click fetches one provider-labeled echo, cached per session. The WebRTC inspector (js/webrtc.js) gathers ICE candidates on a loopback peer connection, reports the selected pair and getStats counters, then tears everything down; mDNS-masked host addresses are labeled, never de-obfuscated. The traffic observer (js/traffic.js) snapshots this page's own Resource Timing entries with filter, per-origin rollup, protocol breakdown, and waterfall, plus an opt-in PerformanceObserver live stream; cross-origin sizes hidden by headers are flagged, never zeroed, and a dedicated panel documents the impossible capabilities. The monitor dashboard (js/monitor.js) charts per-run probe medians, per-run throughput, and cumulative observed bytes with a session rollup and timestamped event log; empty until you measure. Reports and export (js/export.js) save the measured session as source-stamped JSON plus per-section CSV downloads with a printable preview and a persistence panel (key, counts, size, explicit clear); empty sessions export empty sections, never invented rows.

Verification

Run python3 netpulse/tests/test_netpulse.py plus python3 netpulse/tests/test_traffic_monitor.py plus python3 netpulse/tests/test_export_report.py, open index.html?selftest=1 for ALL PASS, toggle offline for the banner path, open Traffic for the own-page snapshot and waterfall, open Monitor after a probe for per-run charts, open Reports to download the stamped JSON and CSV set and print the source-stamped preview, check Firefox/Safari for the honest empty card, and confirm 390 px single-column with keyboard tab paths.
