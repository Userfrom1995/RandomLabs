Method notes

Connection profile reads navigator.connection at boot and on its change event; downlink and RTT are browser estimates, not benchmarks. Online state uses navigator.onLine plus window events. Device context is labeled hint-only. The capability gate in js/capabilities.js drives all honest rendering. Session events persist in localStorage under netpulse.v1 (500-event cap, explicit clear).

Verification

Run python3 netpulse/tests/test_netpulse.py, open index.html?selftest=1 for ALL PASS, toggle offline for the banner path, check Firefox/Safari for the honest empty card, and confirm 390 px single-column with keyboard tab paths.
