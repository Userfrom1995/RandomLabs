  <h2>How it works</h2>
  <p>The orbital core is pure TypeScript, unit-tested in Node with no
  browser:</p>
  <ul>
    <li><code>src/kepler.ts</code> — Kepler's equation solver, mean-anomaly
    integration, orbital position/velocity/path in the J2000 ecliptic frame.</li>
    <li><code>src/bodies.ts</code> — the catalog: six Keplerian elements plus a
    visual config (texture kind, exaggerated radius, base color, albedo,
    specular, optional ring spec).</li>
    <li><code>src/math.ts</code> — vectors, 4×4 column-major matrices,
    look-at/perspective, inverse, easing.</li>
    <li><code>src/noise.ts</code> — seeded 2D value noise + fBm for
    deterministic textures.</li>
  </ul>
  <p>The render layer is plain WebGL1:</p>
  <ul>
    <li><code>src/shaders.ts</code> — three GLSL programs: textured Phong
    (<em>lit</em>), flat color (<em>unlit</em>), and additive sprite for the
    Sun's glow billboards.</li>
    <li><code>src/geometry.ts</code> — UV sphere, ring annulus, quads,
    polylines, point clouds.</li>
    <li><code>src/textures.ts</code> — procedural painters (ImageData → WebGL
    texture, no canvas).</li>
    <li><code>src/renderer.ts</code> — scene draw calls + a ray-casting
    picker for click-to-fly.</li>
    <li><code>src/camera.ts</code> — free-fly camera with exponential follow
    damping.</li>
    <li><code>src/ui.ts</code> / <code>src/main.ts</code> — the HUD, control
    bar, input, and the frame loop.</li>
  </ul>

  <h2>Design choices</h2>
  <ul>
    <li><strong>Distances are honest, sizes are not.</strong> Orbital radii
    keep their real relative distances (1 AU = 100 world units); planet radii
    are scaled up so they are visible.</li>
    <li><strong>Real periods.</strong> The catalog stores actual sidereal
    periods rather than a Kepler-third-law fit, so the relative orbital speeds
    are accurate.</li>
    <li><strong>Determinism.</strong> The PRNG, noise, and painters are all
    seeded, so every visit renders the same universe — and the orbital math is
    unit-tested.</li>
    <li><strong>Portability.</strong> WebGL1 and ES2020 output; no pointer
    lock, so it works embedded in an iframe.</li>
  </ul>

  <h2>Running it locally</h2>
  <pre><code>cd orrery
npm install        # dev-only: TypeScript + esbuild
npm run test       # 43 unit tests (orbital core)
npm run typecheck  # strict TS
npm run build      # bundle src/main.ts → app.js</code></pre>
  <p>The bundled <code>app.js</code> is committed, so the site needs no build
