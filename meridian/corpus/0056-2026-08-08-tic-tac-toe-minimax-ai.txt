# Tic-Tac-Toe

A clean, responsive Tic-Tac-Toe game built with plain HTML, CSS, and JavaScript — no dependencies, no build step.

## What Was Built

A complete browser-based Tic-Tac-Toe game with two modes (PvP and vs Computer), two difficulty levels (easy random and hard minimax AI), a scoreboard, and a dark glassy UI. The minimax AI is unbeatable — verified across 500 simulated games with 0 X wins.

## Files

- `index.html` — Game markup
- `styles.css` — Dark glassy theme, responsive
- `script.js` — Game logic, minimax AI, score tracking
