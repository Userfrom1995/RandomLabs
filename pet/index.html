Desktop Pet

A cross-platform interactive companion: stdlib-only Python, offline by default, honest about platform limits.

What it is

A lightweight, always-on-top desktop companion that feels alive: it idles, wanders, plays, sleeps, and reacts to you, with a nameable personality and procedural animation drawn from canvas primitives. Six characters share one behavior brain with their own bodies, palettes, motion styles, and voices: Pip the blob-cat, Bramble the fox, Mochi the slime, Kiki the sparrow, Rusty the robot, and Luna the moth-dragon. Switch any time with the buttons above, from the characters command, or live in the desktop window. The behavior brain runs headlessly and the on-screen window renders it; gentle clicks stroke it into affection streaks, feeding opens a munch animation, Play starts a scored ball-toss mini-game, and a bedtime schedule tucks it in at night.

Behavior brain

Tick state machine over needs: idle, walk, play, sleep, react. O(1) per tick at 10 Hz.

Companion window

Borderless topmost window with drag-carry, speech bubble, and right-click menu. Open it with python -m pet gui.

Play layer

Stroke streaks, feed-to-munch, a scored ball-toss rally (first to 5 catches), and a 22:00 to 7:00 bedtime routine with a menu toggle.

Personality

Seeded offline dialogue pools per mood and event, no repeats until exhausted.

Persistence

Atomic JSON saves in the platform user-data dir, corrupt files backed up.

Settings

Name, behavior toggles, transparency, size, bedtime hours, and start-at-login, all restored on restart.

Character catalog

Six originals share one behavior brain, and every stat difference is data in the trait tables, never a branch in the code. Stats carry across switches, and installed creator packs join the same switcher. Try each one with the buttons above, with python -m pet characters switch ID, or live in the desktop window:

Pip the blob-cat (balanced)

The baseline every other character scales from. Standard hunger, energy, and affection rates, a 90-second antic rhythm, and the warm shared voice that backs every pack character. Try: characters switch pip.

Bramble the fox (playful)

Affection-hungry zoomies: hunger builds 1.25x, affection fades 1.4x, walks at 1.6x speed with a play-biased brain, and catches the ball in a 1.3x radius. Chatters every 60 idle seconds in exclamation-heavy bursts.

Mochi the slime (sleepy)

Cuddle-positive puddle: half-speed waddle, sleep-biased brain, affection that lingers (0.6x fade). Gentle clicks grant extra affection, snacks restore 1.25x hunger, and the munch animation purrs on for 4.5 seconds.

Kiki the sparrow (curious)

Darting walker at 1.4x speed with a startle-prone brain. Improvises chatter every 45 idle seconds, the fastest antic rhythm in the cast, in a chirpy voice that narrates everything it notices.

Rusty the robot (grumpy-cute)

Poke-tolerant and literal: damped startle response, snacks that barely register (0.8x, it runs on oil), and a 180-second antic rhythm. Answers in dry beep-studded lines. Beep.

Luna the moth-dragon (nocturnal)

Night drifter with hovering motion and winged geometry. Savours meals a little more (1.1x, 3.5-second munch) and answers in dreamy moonlit lines, with night antics paced at 120 idle seconds.

Creator packs extend this gallery without touching the core: the bundled Sunny Pack example adds Sunny the sun-sprite and Ember the ember-fox through the same JSON path third parties use (see Creator packs below).

Requires Python 3.10 or newer. No third-party packages for run-from-source.

python -m pet characters switch mochi
python -m pet run --ticks 300 --seed 7
python -m pet settings --set wander=off --set alpha=0.8

python -m pet service start

Interactions

  • Single click: stroke. Repeat gentle clicks for an affection streak and a purring celebration.
  • Double click: poke. Startle reaction plus a context line.
  • Press-drag: pick up and carry. The pet dangles; dropping shows a relieved line.
  • Right click: menu with Feed, Play, Sleep/Wake, Sleep schedule toggle, Settings, About, Quit.
  • Speech bubble: mood-labeled chatter above the pet; toggle it in Settings without muting system notices.

Settings tour

Settings on the menu (or python -m pet settings) manages the persisted configuration: pet name, wander toggle, play-invitation toggle, bedtime routine toggle plus bedtime and wake hours (HH:MM), speech-bubble chatter toggle, always-on-top toggle, transparency (0.3..1.0), size (0.5..3.0, multiplied by display DPI), and start-at-login. The dialog applies changes live; restart restores name, stats, settings, and window position.

Always on: background service and tray

The pet stays alive with no window open through the background service, which ticks the same headless brain at 10 Hz with debounced atomic saves in the shared user-data dir. Starts are single-instance behind a PID lockfile (a second start reports the live pid; stale locks are reclaimed with a notice), and stop ends the process with a graceful save-and-exit. The tray abstraction tries the optional pystray extra where installed, then a thin native shim, then the stdlib mini-controller where the window itself doubles as the controller; every denied path renders an honest note instead of an exception.

python -m pet service start
python -m pet service status
python -m pet service logs
python -m pet service switch bramble
python -m pet service show
python -m pet tray status

Downloads and native installers

Versioned installers are published on GitHub Releases (tag desktop-pet-vX.Y.Z) by the native pet-release.yml pipeline: Windows exe plus setup, macOS app plus pkg plus dmg, Linux deb plus AppImage plus rpm, every artifact smoked (install, selftest, service cycle, uninstall-clean) before publish. Each release ships SHA256SUMS.txt; verify before running:

shasum -a 256 DesktopPet-*.pkg
Get-FileHash .\dist\desktop-pet.exe -Algorithm SHA256

Honest note: release binaries are unsigned. Windows SmartScreen may warn on first launch (choose More info plus Run anyway); on macOS right-click plus Open the app once to clear Gatekeeper; on Linux run chmod +x on the AppImage. Prefer run-from-source (python -m pet, stdlib only, nothing to trust) if that worries you.

Prefer to build it yourself? The pet is source-first, and every recipe below reproduces the release artifacts bit-for-behavior. Build the one-file binary first, then wrap it per OS. Every recipe is fail-closed, writes checksums, and runs a bundle selftest before declaring success; the version comes from pet/__init__.py in every script, never a copied literal.

No binary needed to run from source (stdlib-only, nothing to install):

bash pet/packaging/install.sh [--service] [--character ID]
bash pet/packaging/uninstall.sh [--purge]

On Windows (PowerShell): install.ps1 [-Service] [-Character ID] and uninstall.ps1 [-Purge]. Install verifies the interpreter, runs selftest, and enables launch-at-login (--service points it at the background service). Uninstall stops the service and removes autostart, leaving saves unless purged.

Verify any binary you build or receive, and compare against dist/SHA256SUMS.txt written by your own build:

shasum -a 256 dist/desktop-pet
Get-FileHash .\dist\desktop-pet.exe -Algorithm SHA256

Creator packs

Anyone can ship new characters as data, no core changes needed: a pack directory (or zip) with a pack.json manifest plus one file per character under characters/, validated against pet/packs/schema.json. Installs merge into the live catalog with trait rates, dialogue voices, converse replies, palettes, and sprite hints; built-ins win slug collisions with a notice, and unknown character ids in saves fall back to Pip with a notice.

python -m pet pack validate ./my-pack
python -m pet pack install ./my-pack
python -m pet pack list
python -m pet pack show sunny-pack
python -m pet pack remove my-pack
python -m pet characters switch sunny

Validation is strict before anything is copied: slug shape, semver plus engine range, body-plan allowlist, clamped trait ranges, dialogue pools of at least 3 lines, zip traversal plus size caps. Corrupt installed packs are moved aside with a notice instead of blocking the catalog. The worked example at pet/packs/examples/sunny-pack adds Sunny and Ember and proves the third-party path end to end.

Command reference

  • python -m pet run [--ticks N] [--seed S]: run the brain headlessly.
  • python -m pet gui [--scale F] [--alpha A]: open the on-screen companion.
  • python -m pet characters (list|show ID|switch ID): the six-character catalog and live switching.
  • python -m pet pack (validate SRC|install SRC|list|remove SLUG|show SLUG): creator packs: validate, install, list, show, or remove third-party character packs.
  • python -m pet talk TEXT: chat with the pet offline (converse is an alias).
  • python -m pet service (start|stop|status|logs|show|hide|switch ID): background service lifecycle on the shared save.
  • python -m pet tray (status|show|hide): system-tray state, with an honest note where no tray host answers.
  • python -m pet settings / startup / notify / selftest: persisted settings, launch-at-login, OS notes, headless selftest.

Troubleshooting

  • No window today, no display found: start a graphical session first, or use python -m pet run headlessly. Force this path anywhere with DESKTOP_PET_NO_DISPLAY=1.
  • tkinter is missing (Linux): install python3-tk from your distro, or stay headless.
  • Save file corrupt: the pet starts fresh and keeps the old file with a .bak suffix. Nothing is deleted silently.
  • Pet always sleepy: energy restores only in SLEEP. Send it to sleep and it wakes rested.
  • Pet falls asleep at night: the 22:00 to 7:00 routine tucks it in. Wake it for a 2-minute grace window, or switch the routine off.
  • Deterministic replay: pass --seed to run for a reproducible session.
