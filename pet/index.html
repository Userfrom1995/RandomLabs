Desktop Pet

A cross-platform interactive companion: stdlib-only Python, offline by default, honest about platform limits.

Live showcase

This is the real pet, drawn with the same pose math as the desktop app (pose_for plus shapes in pet_app/sprite.py, mirrored here in canvas calls). Pick an activity and watch it move:

Poses blend with the same smootherstep easing as the app, so switches glide instead of snapping. The desktop window redraws every 50 ms from the same functions.

What it is

A lightweight, always-on-top desktop companion that feels alive: it idles, wanders, plays, sleeps, and reacts to you, with a nameable personality (Pip by default) and procedural animation drawn from canvas primitives. The behavior brain runs headlessly and the on-screen window renders it; gentle clicks stroke it into affection streaks, feeding opens a munch animation, Play starts a scored ball-toss mini-game, and a bedtime schedule tucks it in at night.

Behavior brain

Tick state machine over needs: idle, walk, play, sleep, react. O(1) per tick at 10 Hz.

Companion window

Borderless topmost window with drag-carry, speech bubble, and right-click menu. Open it with python -m pet gui.

Play layer

Stroke streaks, feed-to-munch, a scored ball-toss rally (first to 5 catches), and a 22:00 to 7:00 bedtime routine with a menu toggle.

Personality

Seeded offline dialogue pools per mood and event, no repeats until exhausted.

Persistence

Atomic JSON saves in the platform user-data dir, corrupt files backed up.

Settings

Name, behavior toggles, transparency, size, bedtime hours, and start-at-login, all restored on restart.

Quickstart per OS

Requires Python 3.10 or newer. No third-party packages for run-from-source.

python -m pet selftest
python -m pet gui
python -m pet gui --scale 1.5 --alpha 0.9
python -m pet run --ticks 300 --seed 7
python -m pet settings --set wander=off --set alpha=0.8
python -m pet startup status

Interactions

  • Single click: stroke. Repeat gentle clicks for an affection streak and a purring celebration.
  • Double click: poke. Startle reaction plus a context line.
  • Press-drag: pick up and carry. The pet dangles; dropping shows a relieved line.
  • Right click: menu with Feed, Play, Sleep/Wake, Sleep schedule toggle, Settings, About, Quit.
  • Speech bubble: mood-labeled chatter above the pet; toggle it in Settings without muting system notices.

Settings tour

Settings on the menu (or python -m pet settings) manages the persisted configuration: pet name, wander toggle, play-invitation toggle, bedtime routine toggle plus bedtime and wake hours (HH:MM), speech-bubble chatter toggle, always-on-top toggle, transparency (0.3..1.0), size (0.5..3.0, multiplied by display DPI), and start-at-login. The dialog applies changes live; restart restores name, stats, settings, and window position.

Troubleshooting

  • No window today, no display found: start a graphical session first, or use python -m pet run headlessly. Force this path anywhere with DESKTOP_PET_NO_DISPLAY=1.
  • tkinter is missing (Linux): install python3-tk from your distro, or stay headless.
  • Save file corrupt: the pet starts fresh and keeps the old file with a .bak suffix. Nothing is deleted silently.
  • Pet always sleepy: energy restores only in SLEEP. Send it to sleep and it wakes rested.
  • Pet falls asleep at night: the 22:00 to 7:00 routine tucks it in. Wake it for a 2-minute grace window, or switch the routine off.
  • Deterministic replay: pass --seed to run for a reproducible session.
